# suanqiu-oss

算逑的开源部分：确定性的命理排盘库与相关工具。只包含可复现的计算，不含 AI 解读。

The open-source side of suanqiu: deterministic Chinese metaphysics chart engines.

| 项目 | 说明 | 许可证 |
|---|---|---|
| [ziwei-chart](https://github.com/suanqiu-oss/ziwei-chart) | 紫微斗数排盘：本命十二宫安星、大限 / 流年 / 流月视图、可选真太阳时，输出带版本号的 JSON | Apache-2.0 |
| [liuyao-chart](https://github.com/suanqiu-oss/liuyao-chart) | 六爻排盘：纳甲、六亲、六神、世应、伏神与变卦，输出带版本号的 JSON | Apache-2.0 |
